## Run locally
Open `index.html` or run `python -m http.server 8080`.

## GitHub Pages
This repository includes a GitHub Actions workflow that publishes the repository root. In repository **Settings → Pages**, select **GitHub Actions** as the source if Pages has not been enabled. The CV link points to the existing file at `https://ammar.bond/CV.pdf`; this file is not copied into this repository.
